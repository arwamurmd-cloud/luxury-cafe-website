# Eat Bae Luxury Experience

Create an award-winning luxury café website for EAT BAE with a soft, elegant, premium, Pinterest-inspired aesthetic that feels like a high-end hospitality brand rather than a typical restaurant website. Use the provided color palette (#D8CB8C, #E8C997, #E58D4B, #C4534F, #F2D54A, #F7F7F5, #2E1D1A) and maintain a light, airy, sophisticated atmosphere with abundant whitespace, editorial-style layouts, rounded corners (24px), soft shadows, glassmorphism accents, and flawless visual hierarchy. Typography should use Playfair Display for headings and Inter for body text, with a hero title of 72px desktop/56px tablet/42px mobile, section titles 48px, body text 18px, and elegant spacing throughout. The homepage should include a full-screen cinematic hero section with a beautiful open-air café image/video, subtle parallax movement, smooth image masking reveals, luxury text animations, CTA buttons (Explore Menu, Reserve Table), followed by About Us, Signature Best Sellers, Café Experience Gallery, Google Reviews, Why Choose Eat Bae, Instagram Moments, Contact & Location, and a premium footer. The Best Sellers section should showcase ramen, coffee, desserts, and brunch specials using large interactive cards with hover lift, zoom, soft glow, and depth effects. The gallery should feel immersive with parallax scrolling, smooth image transitions, hover zoom, staggered reveals, mouse-reactive movement, and luxury storytelling rather than a basic grid. Customer reviews should be displayed in elegant glassmorphism cards with slow auto-scroll and hover interactions. Every image across the website must have smooth reveal animations, subtle scale effects, mask transitions, parallax movement, and premium hover states so the site never feels static. The navbar should be sticky, transparent initially, transforming into a glassmorphism navigation bar on scroll with smooth blur and shrink effects. Buttons should feature magnetic hover effects, elegant color transitions, and soft expansion animations. The entire experience should feel cinematic, luxurious, modern, and memorable, with slow refined motion, smooth page transitions, and buttery scrolling. Build using Next.js 15, TypeScript, Tailwind CSS, shadcn/ui, GSAP, Framer Motion, Lenis Smooth Scroll, Sanity CMS, Supabase, Cloudinary, Google Maps API, and Vercel deployment, ensuring perfect responsiveness, accessibility, SEO optimization, and 90+ Lighthouse performance. The final result should feel like an Awwwards-winning luxury café experience where visitors instantly feel that Eat Bae is not just a café, but a destination worth visiting.
